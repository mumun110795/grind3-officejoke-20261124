## About this entry

The line is built on a very current office ritual: defending your day by
blocking "focus time" on a shared calendar. Anyone who has done it knows the
block is treated less like a wall and more like a suggestion, so the joke lets
that truth set itself up quietly and saves the laugh for the last three words —
the title of the meeting that stomps all over the block is a training session
about respecting it. No boss jokes, no printer gags; just one specific,
recognisable calendar moment with the twist held back to the end of the line.

## Run it

```sh
node main.ts
```

This writes `entry.txt` (the joke, UTF-8, one line) into the output
directory. The directory defaults to `/output`; override it with the
`OUTPUT_DIR` environment variable:

```sh
OUTPUT_DIR=/tmp/my-out node main.ts
```
